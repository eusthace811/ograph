Hand labels for scripts/eval/misled_by.py, written and committed before the script ran on these runs.

Sample: 20 of the 99 wrong runs (an agent arm, status fail, a non-empty ROOT) of the seen sample
(suite rcaeval: --sample 30 --seed 12) in docs/evidence/agent-rca-haiku, drawn with
random.Random(20261125).sample(sorted((arm, case, run, root)), 20). No held-out (rcaeval-miss) or
demo transcript was read.

How each run was read: the transcripts keep 3000 characters of each tool output, and the wrong
application is often past the cut (an ograph_chains answer is 4-9 KB). scripts/eval/replay_calls.py
re-executed each run's calls against the same case with a binary of the same ograph-core and
ograph-cli (74b3696; no change to either since ee48efb, the run's binary) and checked every replayed
output against the kept text: 156 of 161 calls matched (144 exact, 12 close), 3 did not (two
`find` listings in another file order, one `ls`), and 2 large outputs were previews in the run,
so the preview stands. The labels below come from
reading those outputs call by call, not from any attribution code.

Rubric. The first call whose output presents the wrong application as a candidate cause: the
output attaches a fault signal to it. Counts: an event on it (before, suspects), a chain or a
rank for it (chains), an anomaly, error count, deviation or onset that the agent's own script
printed for it, an error log line from it. Does not count: the catalog, ownership, dependency
lists or `blast` (no signal), CSV headers, a scope list, normal log lines or plain line counts,
the skill's text, and cite_check echoing the agent's own draft. Several ograph commands in one
Bash call: the tool is the command whose part of the output carries the signal.

tool: before, chains, suspects, similar, why, blast, sparql (ograph's, as MCP tools or CLI
commands in Bash), own (the agent's own grep, awk or Python over the raw files), read.
signal: the strongest signal on the wrong application in that output.
